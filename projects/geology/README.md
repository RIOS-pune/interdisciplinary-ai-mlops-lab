# Geology + AI: Deccan basalt groundwater mapping

**Science:** lithology, slope, drainage density, lineaments, geomorphology, borewell yield, groundwater depth, spatial scale.
**CS:** geospatial joins, CRS consistency, raster resampling, spatial cross-validation (blocks rather than random nearby pixels), gradient-boosting baselines and uncertainty maps.
**Data:** geoscience field points, India-WRIS and permitted DEM/remote sensing from USGS.
**Deliverables:** GIS layer manifest, feature notebook/script, leakage-free validation, interpreted map.
**Status:** project charter only, not a runnable GIS pipeline.
