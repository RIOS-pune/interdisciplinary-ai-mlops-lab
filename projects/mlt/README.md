# Medical Laboratory Technology + AI: blood cell classification

**Science:** cell morphology, staining protocols, labeling/quality, clinical terminology.
**CS:** image QC, augmentation only in training, CNN baseline, patient-level splitting, sensitivity/specificity and calibration.
**Data:** properly licensed, peer-reviewed public datasets with provenance.
**Deliverables:** source manifest, image QA, confusion matrix, error analysis.
**Status:** project charter only, not a runnable imaging pipeline; not for clinical deployment.
