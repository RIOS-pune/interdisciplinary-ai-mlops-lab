# Chemistry + AI: molecular-property prediction

**Science:** SMILES, descriptors, functional groups, assay conditions, endpoints and units.
**CS:** molecular featurization, RDKit, baseline regression/classification, molecular scaffold split, uncertainty and applicability-domain assessment.
**Data:** MoleculeNet and ChEMBL (follow their data access rules).
**Deliverables:** curated compound table, endpoint checks, scaffold-split metrics, explainability report.
**Status:** project charter only, not a runnable QSAR pipeline.
