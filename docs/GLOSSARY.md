# Beginner's scientific and ML glossary

| Term | Plain-English meaning |
|---|---|
| LUAD | Lung adenocarcinoma, a subtype of non-small-cell lung cancer |
| LUSC | Lung squamous cell carcinoma, another subtype |
| RNA-seq | Sequencing method to measure RNA transcripts in a sample |
| Gene expression | An estimate of how active a gene is in a sample |
| Somatic mutation | DNA alteration acquired in cells rather than inherited in all body cells |
| CNV | Copy-number variation: genomic region appears in different copy counts |
| Biomarker | Measurable indicator associated with a biological state; needs validation |
| Feature | The numerical measurement provided to an ML model |
| Label | The answer the model is trained to learn, e.g., LUAD/LUSC |
| Train/test split | Keep part of data unseen until final evaluation |
| Leakage | Test-set or answer information accidentally influences training |
| Cross-validation | Repeated training/validation splits to estimate robustness |
| Confusion matrix | Counts of correct and mistaken predictions for each class |
| Balanced accuracy | Average recall across classes, helpful for imbalance |
| Spatial autocorrelation | Nearby locations tend to be similar, which can inflate map-validation scores |
| Scaffold split | Chemistry split grouping related molecular cores to reduce overly optimistic validation |
