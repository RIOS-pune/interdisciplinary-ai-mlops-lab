# Team workflow

1. Domain-science lead defines the question, dataset eligibility, units, inclusion rules and scientific interpretation.
2. CS lead creates scripts, data checks, split strategy, baseline metrics and reproducible run commands.
3. Both review confounding, leakage, ethics and limitations before accepting results.
4. Keep one issue per deliverable, one working branch per task, and pull requests with evidence.
5. Save a short weekly research log: hypothesis, datasets, code commit, result, blocker, next step.

## Branch conventions
`main` stable; `feature/g2-expression-eda`, `feature/g1-mutation-features`, `docs/g3-multiomics-method` for contributions. Require peer review before merging.

## Student deliverables
Research proposal, problem glossary, source and provenance manifest, EDA, baseline, tuned evaluation, model card, report, reproducible README, 5-minute demo.
